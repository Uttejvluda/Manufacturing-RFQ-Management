# Manufacturing RFQ Management System

A comprehensive **Request for Quotation (RFQ) management system** built for manufacturing environments. Streamlines vendor communication, quote tracking, and procurement decision-making.

---

## 🚀 Features

### Core Modules
- **RFQ Management** – Create, track, and manage RFQs
- **Vendor Management** – Maintain supplier database and history
- **Quote Comparison** – Side-by-side quote analysis
- **Authorization & Security** – Role-based access control
- **Plant Management** – Multi-location support

### Key Capabilities
- ✅ Create and publish RFQs
- ✅ Track vendor responses in real-time
- ✅ Compare quotes with automated scoring
- ✅ Status tracking (Sent → Received → Reviewing → Awarded)
- ✅ Export reports and analytics
